# Fort Myers local SEO and website audit checklist

Use this checklist with the
[website review record](../templates/website-review-record.md). Mark each item
Observed, Reported, Unknown, or Not applicable and attach evidence where useful.

## Business identity

- [ ] The public business name is consistent.
- [ ] The canonical website URL is clear.
- [ ] A physical address is published only when verified and eligible.
- [ ] Service-area language does not imply a storefront.
- [ ] Public phone and email details are consistent where supplied.
- [ ] Each real location has its own record.
- [ ] Categories describe actual services.
- [ ] Existing public profiles do not conflict with the website.

## Homepage clarity

- [ ] The main service is understandable without scrolling far.
- [ ] The intended customer is identifiable.
- [ ] Fort Myers or the real service area appears in useful context.
- [ ] The primary action is visible.
- [ ] Important claims have proof nearby.
- [ ] Navigation labels match what customers seek.
- [ ] The mobile layout preserves the same core message.

## Service pages

- [ ] Each primary service has a dedicated, useful page.
- [ ] The page explains the service in specific language.
- [ ] The page answers common buying questions.
- [ ] Service-area references are accurate.
- [ ] Internal links connect related services and guides.
- [ ] The next action matches the page intent.
- [ ] Similar city pages contain distinct, useful information.

## Contact path

- [ ] Phone links use a valid `tel:` target when a phone is published.
- [ ] Booking links open the intended calendar.
- [ ] Forms have clear labels and error states.
- [ ] Consent language matches the information collected.
- [ ] The user receives a clear confirmation state.
- [ ] Leads reach the intended inbox, CRM, or operator when testing is authorized.
- [ ] Mobile visitors can complete the main action comfortably.

## Crawl and indexability

- [ ] Important pages return a successful HTTP response.
- [ ] Canonical URLs point to the intended public URL.
- [ ] Robots rules do not block important pages.
- [ ] The XML sitemap lists canonical indexable pages.
- [ ] Titles are unique and describe the page.
- [ ] Meta descriptions are useful and specific.
- [ ] Each page has one clear primary heading.
- [ ] Redirects resolve in one intended hop where practical.
- [ ] Broken internal links are corrected.

## Structured information

- [ ] Organization or appropriate business markup matches public facts.
- [ ] No unverified address appears in LocalBusiness markup.
- [ ] Service markup identifies the actual provider and service.
- [ ] Article author and publisher records resolve correctly.
- [ ] Breadcrumb markup matches visible navigation.
- [ ] Structured data passes current syntax checks.

## Mobile, performance, and accessibility basics

- [ ] The page includes a responsive viewport declaration.
- [ ] Content does not cause document-level horizontal scrolling.
- [ ] Text remains readable without zooming.
- [ ] Tap targets are large enough for touch input.
- [ ] Images reserve space and avoid avoidable layout movement.
- [ ] Important images have useful alternatives.
- [ ] Forms expose labels and instructions.
- [ ] Main regions and headings follow a usable hierarchy.
- [ ] Keyboard users can reach and understand interactive controls.
- [ ] Obvious contrast problems are recorded.

## Trust and ownership

- [ ] The business or publisher is identifiable.
- [ ] Named authors have linked profile pages where relevant.
- [ ] Claims, testimonials, and examples have a visible source.
- [ ] Commercial relationships are disclosed when relevant.
- [ ] Privacy and terms pages are present when the workflow requires them.
- [ ] Copyright and contact information are current.

## Measurement

- [ ] Search Console ownership is known.
- [ ] Analytics ownership is known.
- [ ] Calls, forms, or bookings have a defined measurement path.
- [ ] Campaign parameters survive the intended handoff where applicable.
- [ ] The team can distinguish a visit, an inquiry, and a qualified conversation.
- [ ] Unknown account-level measurements remain labeled Unknown.

## Priority summary

After the review, record:

1. The finding most likely to block discovery.
2. The finding most likely to block understanding or trust.
3. The finding most likely to block contact.
4. The first change to verify.
5. The evidence needed for the recheck.
