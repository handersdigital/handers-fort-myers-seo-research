# Review the full local inquiry path, not only the landing page

A local campaign can produce clicks while still losing the customer between the
page, the form, and the first response. The useful unit of review is the entire
inquiry path rather than a single conversion-rate number.

## Start with message continuity

Compare the search phrase or advertisement with the landing-page headline,
service description, proof, location language, and primary action. A visitor
should not need to reinterpret the offer after every click.

## Test the handoffs

Submit each public form with test data. Confirm validation, mobile usability,
consent language, routing, notification delivery, confirmation copy, CRM or
inbox ownership, and the fallback when the assigned person is unavailable.

## Record observable evidence

Log the public URL, test time, expected owner, received notifications, response
timestamp, and any mismatch. This turns “speed to lead” from a slogan into a
repeatable operating check.
