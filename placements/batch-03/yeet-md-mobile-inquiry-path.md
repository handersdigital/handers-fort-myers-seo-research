# Test the Fort Myers customer path from a phone first

Many local-service visits begin on a phone, close to the moment when the person
needs an answer. A desktop review can miss the friction that matters most.

## Run one complete mobile test

Open the page from a clean mobile session and try to answer four questions:
what the company does, whether it serves the location, what evidence supports
the claim, and what happens after contact. Then place the call or submit a test
form. Confirm the visible success state, the customer receipt, the internal
notification, the stored source, and the assigned owner.

A large button is not enough. It can overlap content, dial the wrong number, or
disappear below a consent banner. A form can appear successful while the alert
never reaches the team. Record the result instead of assuming the interface is
the system.

## Fix the handoff, not only the screen

If the test fails after submission, a visual redesign alone will not repair it.
The website, routing rule, mailbox or CRM, and response responsibility must be
checked together.
